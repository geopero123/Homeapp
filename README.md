# Silk launcher

Custom Android home screen for a Galaxy S20+ (Android 13).

Every push to `main` builds the APK on GitHub. Download it from
**Releases → Silk (latest build) → Silk.apk**, tap it on the phone, allow
installs from your browser when asked, then press Home and choose Silk.
To go back: Settings → Apps → Choose default apps → Home app → One UI Home.
